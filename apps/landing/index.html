Chrome extension

DarshanDesk

Prepare pilgrims in the extension, sync with your agency API, and assist filling official TTD pilgrim fields. You still submit, declare, and pay yourself on the portal.

Download

Private beta ZIP (unpacked install). Replace the API URL in Settings after install if needed.

Download extension v1.0.0

Install (Chrome)

  1. Unzip the download.
  2. Open chrome://extensions → Developer mode → Load unpacked.
  3. Select the unzipped folder (it contains manifest.json at the top level).
  4. Pin DarshanDesk → Create account or sign in.
  5. Set API URL to your production host (e.g. https://api.yourdomain.com).

Not affiliated with TTD. No captcha, OTP, payment, or final booking submission automation. For Chrome Web Store listing, build with production API env vars — see EXTENSION_PUBLISHING.md in the repo.
