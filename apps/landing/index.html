What DarshanDesk does not do

  • Not affiliated with Tirumala Tirupati Devasthanams (TTD).
  • No auto-submit, no captcha bypass, no OTP or payment automation.
  • No guarantee of ticket availability—quota is decided on the official portal.

Install in Chrome

  1. Download the ZIP above (opens Google Drive) and extract to a folder (e.g. DarshanDesk-ext).
  2. Open chrome://extensions → turn on Developer mode.
  3. Load unpacked → select the folder that contains manifest.json at the top level.
  4. Pin DarshanDesk → Create account or sign in with your agency email.
  5. In Settings, set API URL to https://darshan.totallylearns.com (no trailing slash) if not already configured.
  6. Add TTD account → pilgrims → preparation → open TTD Pilgrim Details → Fill → Sync & Fill.

For agencies

One extension per operator machine. Central API on your domain keeps pilgrim prep and audit trails under your agency license. Need Chrome Web Store distribution? Rebuild the ZIP with production env vars from the GitHub repo.
